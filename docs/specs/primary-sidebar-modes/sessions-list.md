# Sessions 列表布局与交互

> 状态：现行契约。（核对于 2026-10-29）

Sessions 模式内容区（`SessionsSidebarContent`）与会话搜索浮层（`SessionSearchPalette`）的布局、行内容、拖放与动画。入口见 [第一侧栏模式](../primary-sidebar-modes.md)；两栏共用的行规则（⋯ 浮在文字上渐隐、hover 随滚动生命周期、NSTableView 复用）以 [双侧栏布局约定](../double-sidebar.md) 为准。

## 布局

```text
[ Handoff | Sessions ]
项目                    ⋯ ＋
▾ lightty                 ⋯
    修复侧栏裁切
    Codex · 20 分钟前
▸ Breeze
最近会话 ◌            [筛选]
  一次临时排查
  Codex · 今天 · scratch
```

- 不内嵌搜索框。筛选图标在“最近会话”标题尾部，打开 lightty 自绘的筛选与管理菜单：Agent、归档、按更新时间 / 名称排序、刷新（加载中变为取消）、各家的原生恢复选择器。
- “项目”与“最近会话”是同一滚动列表中的平级分区，标题字号、颜色、左边距一致，使用正常正文色、无整行 hover。“项目”标题带垂直居中的小号 `chevron.down`（紧随文字，不用文本符号），整体展开 / 收起项目及成员，不改变归组；尾部无边框 `⋯`（更多操作未定义，保持禁用）与 `＋`（新建项目）。
- 项目是可折叠父行，会话是叶子；展开只影响列表，不打开终端，缩进与第二侧栏的树一致。项目行的打开 / 关闭文件夹用配套 Lucide 矢量图标，其余系统图标用 SF Symbols。“暂无项目”用较小常规字重、次级色与缩进，表达状态而非分类。
- 底部状态区固定高度，放空状态与错误摘要（长摘要给完整 tooltip 与辅助功能文本）；没有下一页时隐藏“加载更多”。
- 列表经 `SidebarListScrollView`：左缘距卡片 12pt、滚动容器右缘距卡片 2pt，内部右侧独立保留 16pt 滚动条区，overlay 隐藏时也不改变行宽。滚动条沿用系统偏好（overlay / 始终显示）与小号控件。Handoff 与 Sessions 的行首内边距、更多按钮与次级文字色一致。

## 行内容

- 最近会话行三行：标题；Agent 与本地化时间；目录末级名。项目内紧凑两行，不重复父项目名。完整目录放 tooltip，避免路径挤掉时间。
- 标题取来源提供的名称 / 摘要，缺失时显示“未命名会话 · 短 ID”；清理控制字符、限长、纯文本显示。
- 在 lightty 里开着的会话：标题前 7pt 状态点，与第二行 Agent 图标同列，文字统一右移到列后；点色、呼吸与状态词沿用标签页侧栏（`ShellStyle.dotColor`、`StatusDotBreath`、`PaneStatusLabel`），状态词顶替第二行时间，空闲写“已打开”；成段放在 `trayFill` 凹托里（见 [UI harness](../../UI-harness.md)）。在其他终端开着的用空心点，第二行保留时间并注明（只有 Claude 能判断，Codex 不标，见 [会话接口](../agent-session-apis.md)）。未打开的行不留点位。磁盘变动时间不作为运行中状态。
- 按更新时间排序时，开着的会话排在各自分区最前，彼此按标签页侧栏顺序（窗口 → 标签页 → pane），Agent 活动刷新时间不改变其位置，关闭后回到按时间的位置。项目内按更新时间排序，缺少时间的稳定落后。按名称排序与搜索结果不置顶。
- “最近会话”只展示未归入项目的会话，同一记录不在两处重复。

## 拖放

- 会话可拖到具体的未归档项目行（原生落点提示，成功后展开目标项目）；拖回“最近会话”标题、其下会话行或列表底部空白，统一高亮“最近会话”并解除项目归属。
- 拖放与菜单共用组织模型的 move，不写 Agent 历史。只接受本侧栏列表发起的内部拖动；“项目”总标题、项目内会话行、同归属落点与搜索结果不执行移动。

## 增量更新与动画

- 稳定行 ID 增量更新，保留无关行实例、滚动锚点与选择，不在 reload 时强制选第一行；保存状态变化不重建全表。
- 用户折叠用 `ShellStyle.animationDuration` 的行增删过渡；分区箭头绕独立图层中心旋转，连续操作从当前呈现角度反向。目录分批返回只做无动画增量更新。
- 换位置的行（开关会话进出置顶、刷新改了时间）用表格挪行滑到新位置，时长与曲线同折叠，保留单元格实例；结束后按指针位置重认 hover。“减少动态效果”下折叠无过渡，挪行按删除 + 插入直接到位。
- 相对时间由视图每 30 秒更新可见行，不触发 CLI 查询、不重建行；手动刷新、显示侧栏与目录变化也会更新。

## 搜索浮层与新建

- 顶部搜索按模式路由；Sessions 浮层搜索已加载会话的标题、Agent、目录与 lightty 项目，含本地归档记录，平铺命中并显示归属，不读对话正文。上下键、回车（新标签页续接）、Esc 与点击外部关闭；它是 `SessionsSidebarContent` 的搜索形态，复用 app 级目录与分页 / 错误提示，打开浮层不发起查询。
- 顶部“新建”在 Sessions 模式打开启动浮层的 `.session` 主体（Agent、工作目录、去处），目录默认继承当前终端；不注入 Handoff 文档、不绑定任务，不当作 resume。
