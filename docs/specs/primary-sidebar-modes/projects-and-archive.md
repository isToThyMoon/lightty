# 项目与本地归档

> 状态：现行契约。（核对于 2026-10-29）

Sessions 的项目（Project）分组、会话归属与 lightty 本地归档的规则，以及组织数据的持久化。入口见 [第一侧栏模式](../primary-sidebar-modes.md)；术语（项目、组织数据、移到项目、归档）见 [CONTEXT.md](../../../CONTEXT.md)。

## 项目

- 项目是 lightty 内部的手动会话分组，与文件夹、工作目录及 Agent 的历史存储目录无关；可混合 Claude Code 与 Codex CLI 会话。
- 支持创建、改名、上移排序、展开 / 收起与移除。项目行只切换成员可见性，保留 hover，不呈现持续选中态。
- 用户经拖放或菜单收录会话，每个会话最多属于一个项目；未指定归属的会话进入“最近会话”。“移到项目”只改归属，不合并上下文，不移动 Agent 文件。
- 同名不合并，以稳定 ProjectID 区分；不按 cwd、Git 仓库或目录规则自动分组。cwd 只用于显示与恢复终端，缺失或变化不影响已有分组。
- 移回最近会话即解除归属；移除项目只删 lightty 的分组信息，不删会话或工作目录。

## 本地归档

- Sessions 的“归档”筛选展示 lightty 自己归档的项目与会话，两种 Agent 统一适用；切换筛选不查询、不修改 Agent。
- 单独归档的会话保留项目归属。项目菜单不提供归档；已有的归档项目仍可“恢复项目”，恢复保留分组及成员各自的单独归档状态。
- 从归档项目中单独取回会话用“恢复到最近会话”，并显式移出该项目，避免恢复后仍被项目隐藏。移到其他可见项目或普通移出项目不隐式恢复会话。
- 删除项目只移除分组：继承项目归档的会话回到最近会话，单独归档的会话保持归档；不删除对话或原始文件。
- Codex 原生 active / archived 分区都作为发现来源，原生状态标为 `sourceArchived`，不映射成 lightty 归档；Claude 有无原生归档接口不影响本地组织。

## 持久化

- 项目、手动归属、顺序、折叠与本地归档（项目 ID、会话 key）存于版本化的 `~/.lightty/organization.json`；旧文件缺少归档字段时按未归档读取。启动升级遵循 [持久化契约](../../persistence.md)；写入原子替换，失败保留旧数据并告知用户。
- app 级 `SessionLibrary` 是唯一写入者，窗口只发操作，避免多窗口互相覆盖。目录缓存若落盘与此文件分开：缓存可重建，用户分组不能静默丢弃。
- 原始会话由 Agent 持有；Agent 清理了原始会话时，lightty 的归属引用不构成备份。只有完整刷新成功后才清理失效记录，手动归属仍保留可恢复引用。
