# 标签页分组

标签页分组是第二侧栏中位于标签页之上的窗口内组织层：**分组 › 标签页 › pane**。
它只整理当前窗口的终端现场，不是 Sessions 项目，也不改变 Handoff 任务与 pane 的绑定。

## 模型

- `WindowArrangement` 同时保存有序标签页和有序分组。标签页可选指向一个分组。
- 同一分组的标签页在窗口顺序中始终连续；第二侧栏、`goto_tab` 和快照共用这一份顺序。
- 顶部新建分组与当前标签页无关：创建一张新标签页作为新组的首个成员。标签页菜单里的「移到新分组」才会移动对应标签页。最后一个标签页离开后分组随之删除，不保留空分组。
- 分组名称、顺序和成员关系进入工作区快照。折叠只是当前第二侧栏的展示状态，不落盘。

## 呈现与操作

- 没有分组时保持原有两级列表，不显示「默认分组」或「未分组」。
- 分组行使用容器字重、轻底色、折叠图标和标签页数量。它只折叠内容，不切换终端。
- 分组中的标签页整体增加一级缩进；pane 再按原有关系缩进。单 pane 默认名标签页仍保持单行叶子形态。
- 当前 pane 仍独占最强选中底色；其标签页用容器强调；分组只强调标题和图标，不叠加第三层选中底色。
- 顶部更多菜单提供「新建标签页分组」。标签页菜单提供移入已有分组、移到新分组和移出分组；分组菜单提供新建标签页、重命名和解散。
- 新建标签页默认跟随当前标签页的分组。

## 拖拽

- 标签页在分组内重排；拖到分组行上移入该分组末尾。
- pane 拖到标签页或 pane 行的合并语义不变。pane 拖到标签页间拆成新标签页时，跟随落点所在分组。
- 分组行不是 pane 合并目标，避免「移入分组」与「并入某个分屏树」混用同一落点。

### 单 pane 标签页的双重身份

单 pane 默认名标签页在侧栏中压成一条叶子行。拖拽源同时携带 tab 与 pane 身份，
由落点决定使用哪个身份：

| 落点 | 用户意图 | 结果 |
| --- | --- | --- |
| 侧栏标签页之间的缝隙 | 整理标签页 | 整个 tab 换位，pane 不重建 |
| 分组标题中央 | 收入分组 | 整个 tab 移到该组末尾 |
| 分组标题与第一个子项之间 | 放到组内首位 | 整个 tab 移到该组首位 |
| 组内子项之间 | 组内排序 | 整个 tab 在该组内换位 |
| 标签页容器行中央 | 并入该标签页 | pane 移入目标的分屏树 |
| pane / 叶子行中央 | 放到该 pane 旁边 | pane 插到目标右侧 |
| 终端主区中某个 pane 的半区 | 可视化分屏 | pane 移到对应上/下/左/右侧 |
| 空白区域或源 pane 自身 | 没有有效目标 | 不改变结构 |

普通分屏 pane 没有 tab 身份：它落到顶层缝隙时拆成新标签页，落到分组标题上不响应。
