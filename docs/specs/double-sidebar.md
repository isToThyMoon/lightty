# 双侧栏布局约定

术语见 [CONTEXT.md](../../CONTEXT.md)。第一侧栏双模式的功能设计与待实施内容见
[Handoff 任务 / Sessions 会话](primary-sidebar-modes.md)；本文说明当前布局与需要保持的交互契约。

## 布局与职责

物理顺序：**第一侧栏｜第二侧栏｜终端主区**。

- 第一侧栏是最左侧的浮空卡片，当前展示 Handoff 任务；两侧栏独立开合。
- 第二侧栏展示当前窗口的标签页与终端树，不按第一侧栏的任务选择过滤。
- 终端主区按两栏实际展开宽度让位；第一侧栏关闭时，第二侧栏移到窗口左侧。
- 默认第一侧栏开、第二侧栏关；恢复窗口时使用快照中的开合状态。
- 宽度、边沟与圆角沿用 ShellStyle token；第二侧栏支持调宽、保存宽度及越界左拖关闭。

## 顶部与开合

- 第一侧栏的搜索、建档、收起按钮与红黄绿同一水平线；收起后开关位于标题栏。
- 第二侧栏标题行提供向右分屏、向下分屏、新标签页；其开关是主区左缘 / 第二侧栏右缘的吸边半胶囊。
- 第二侧栏头部避让标题栏；终端主区不额外增加整行标题栏高度。
- 全屏时不可从已脱离当前窗口的红绿灯控件推导顶部高度，使用有效的窗口态测量缓存。
- 开合动画驱动真实约束布局与终端 resize；动画期间抑制 prompt-clear 与 hover，结束后恢复。

## 标签页与终端导航

- 数据源是当前 TerminalWindowController 的标签页与 pane 树，不另建副本。
- 点击未激活标签页切换过去；点击已激活标签页切换折叠；disclosure 独立控制展开。
- 单 pane 且仍叫默认名的标签页以叶子行呈现：不出容器行与计数，一条 pane 行前置标签页图标（与容器行同列同字形）、pane 内容从子级缩进位起，同时承担标签页语义——落点 = 移入该标签页，⋯ / 双击 = 重命名标签页。用户改过名的标签页恢复容器行 + pane 行，名字始终可见；出现第二个 pane 同样展开，关回一个再收起。
- 列表内拖拽分两种意图：落在行与行之间是排序，压在某一行中央带（行高中段 50%）上是合并，合并期间停止让位并高亮目标行。排序的落点按紧邻行判定——下方或上方紧邻是缩进 pane 行则落在那个标签页块内，否则落在标签页之间；折叠的标签页只有一行，块内不存在，要并进去只能拖到它身上。整条标签页（叶子行）落在标签页之间是换位次，落进某个标签页块内是并入；标签页里的分屏 pane 落在标签页之间会拆出来独立成新标签页，落在块内是同树重排。合并落到容器行是移入该标签页，落到 pane 行或叶子行是插到那个 pane 旁边。拖起来的卡片先摘掉 hover 反馈再取快照，所有行长同一个样；卡片带半透明衬底，进入合并态时进一步透明并缩进一圈，目标行的落点框线要透得出来。容器行也可拖动重排：展开着的多 pane 标签页在拖动期间临时折叠成一行（脚下抻开收拢的多行块会让落点对不准），松手后恢复原来的展开状态；容器行只参与排序不参与合并，把一整棵分屏树并进另一个标签页是另一种操作。
- 标签页支持改名、关闭；终端叶子支持前往、关闭。关闭走现有内核确认通路。
- 终端行显示名称、状态及任务 / cwd 信息，长路径优先保留末尾，完整内容通过 tooltip 查看。
- 高频状态变化原地更新展示，不重建整列；刷新应保留滚动位置与选择。
- 两栏列表使用 NSTableView 按可见区域创建视图；Sessions 和标签页列表使用原生视图复用，绑定新行时重置旧内容、交互状态和回调。第二侧栏只保存轻量的行投影与视图工厂，pane 行索引使用弱引用；重新绑定时移除旧身份索引，读取当前状态与 cwd。拖拽位置和相邻终端关系从完整行投影计算，不依赖离屏视图存在。不引入自定义滚动窗口或预加载调度器。
- 两栏开合或第一侧栏模式切换，不改变标签页、分屏树与正在运行的终端。
- 列表保留 AppKit 响应式滚动，不重写 `scrollWheel`；通过原生滚动生命周期与内容位置通知管理 hover。滚动期间统一使用箭头光标，结束后按指针位置恢复反馈；行光标跟踪不持有离屏行。

## 验收

- 两栏分别开关、组合开关、第二侧栏调宽与拖关。
- 先只开第一侧栏，进入全屏，再展开第二侧栏：终端顶部不裁切，侧栏标题不落到底部。
- 多标签页创建 / 切换 / 折叠 / 改名 / 关闭、终端前往与关闭、cwd 与状态刷新。
- 深浅外观、长标题、键盘操作、快速连续开合、旧 macOS 与发布包回归。
